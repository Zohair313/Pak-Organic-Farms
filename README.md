# Pak Organic Farms — Developer & Operator Guide

A complete bilingual (English/Urdu) landing page for Pak Organic Farms Islamabad.

## Quick Start
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Documentation
Comprehensive developer and non-technical operator guides are provided in the documentation folder:
- **Project Structure**: Clean separation of UI (`src/App.jsx`) and content (`src/data/en.json` & `src/data/ur.json`).
- **Images**: Located in `public/images/`.
- **Repository**: [https://github.com/Zohair313/Pak-Organic-Farms.git](https://github.com/Zohair313/Pak-Organic-Farms.git)
